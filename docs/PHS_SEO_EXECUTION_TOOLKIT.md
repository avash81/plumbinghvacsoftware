# PHS SEO Execution Toolkit

This toolkit provides the operational checklists and trackers for maintaining the SEO health and editorial quality of PHS.

---

## 1. Content Writer Checklist

Before publishing any article (review, guide, or comparison), verify the following:

- [ ] **Reader Decision**: Does this page answer the specific decision the reader is trying to make?
- [ ] **Plain Language**: Are we using real operator language (e.g., "dispatching," "flat-rate") instead of generic SaaS buzzwords?
- [ ] **Answer at the Top**: Is the core question answered near the top of the page?
- [ ] **Next Step Obvious**: Is the next logical action (e.g., a comparison or the contact page) clear?
- [ ] **No Friction**: Are there zero pop-ups or sign-up walls?
- [ ] **Human Connection**: **Would a real business owner reading this feel like a real person made it for them?** (The One-Sentence Test)
- [ ] **Authorship**: Is there a clear byline linking to a real author bio?
- [ ] **FTC Disclosure**: Is the disclosure visible above the fold?

---

## 2. Technical SEO Checklist

- [ ] **Meta Tags**: Unique title (<60 chars) and description (<160 chars).
- [ ] **Canonical URL**: Correct canonical tag in the head.
- [ ] **Structured Data**: FAQ or Product schema injected via `SEOHead`.
- [ ] **Core Web Vitals**: Lighthouse performance score >90.
- [ ] **Internal Linking**: At least 3 internal links to other relevant PHS pages.
- [ ] **Mobile Usability**: Comparison tables are readable and interactive on 375px screens.

---

## 3. Quarterly Audit Checklist

- [ ] **Rate Card Verification**: Check if vendor pricing has changed.
- [ ] **Affiliate Link Test**: Ensure all target URLs are still active.
- [ ] **"Last Verified" Date**: Update the frontmatter and visible badge.
- [ ] **Broken Links**: Run a sitewide broken link check.
